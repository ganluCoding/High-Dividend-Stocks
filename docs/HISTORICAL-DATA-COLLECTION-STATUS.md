## 自动更新

已安装用户级 LaunchAgent：`com.highdividend.historical-backfill`。

它每天低频运行一次，每次最多处理 100 只股票和 50 只 ETF，继续选择历史日数少于约 1,000 个交易日的标的。成功批次会自动发布新版本；失败只保留日志和隔离结果。运行日志：

`~/Library/Application Support/HighDividend/logs/historical-backfill.out.log`

手动运行或重新安装：

```bash
python3 scripts/autonomous_history_backfill.py \
  --runtime-root "$HOME/Library/Application Support/HighDividend"
python3 scripts/install_historical_backfill_agent.py --install
```
